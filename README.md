# FilmCraft TS comparison editor

This branch contains a small, independent TypeScript browser editor for comparing FilmCraft-inspired editing with [Irie Cut](https://iriecut.com/). It is a separate implementation, not a port of FilmCraft's Rust engine. [The fork's `main` branch](https://github.com/corey470/filmcraft/tree/main) retains the original Rust FilmCraft source.

Start with [the app README](apps/filmcraft-ts/README.md) for run instructions, tested features, and current limits. The app contains no ArtCraft brand assets. FilmCraft and the ArtCraft Team are credited in plain text.
